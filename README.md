# jordbps.github.io

Personal website of Jordi Buckley-Paules, served by GitHub Pages at https://jordbps.github.io/.

- `index.html`: the whole site. Pages (Home, Rice, Consulting, Teaching, Adventures, Game, Contact) are sections switched by the `#hash`.
- `img/`: photos and logos.
- `game/index.html`: Oryza Basin, a rice, water and flood game. Embedded on the Game page and playable full screen at `/game/`.
- `.nojekyll`: serve files as they are, without a Jekyll build.

To change something, edit the file on GitHub (pencil icon) and commit; the live site updates within a minute or two.
